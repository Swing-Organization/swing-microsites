# Swing × Footwear Launch

Swing Tennis editorial test campaign at `/campaign/footwear-launch/`.

The marketer explicitly approved the supplied golf photography/video as stand-ins on 2026-10-06. The campaign follows the tennis brief without misrepresenting the actual media in accessibility descriptions. Kin Polo, Clara Dress and Luisa Jacket have equal display-only prominence. Prices and shopping destinations are intentionally omitted for this campaign. Both collection CTAs scroll on-page.

All eight selected source files were retrieved from the specified Drive folders and matched against SHA256 values in the existing pinned private media store. Four film derivatives were retrieved from the existing deployed campaign and matched exactly against pinned derivative hashes. CI restores the same immutable private store into this campaign's own ignored `assets-source/`.
